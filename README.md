# ExoplanetExplorer

A .NET command-line project for exploring exoplanets.

## Getting started

Requires the .NET 11 SDK. From the repository root:

```shell
dotnet run --project src/ExoplanetExplorer.Cli
```

Build the solution with `dotnet build` and run the test projects with `dotnet test`.

The solution contains CLI, Core, Data, and Analysis projects, with a corresponding test project for each library. The libraries and test projects are currently empty.
